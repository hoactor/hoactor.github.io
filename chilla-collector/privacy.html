chilla-collector 개인정보처리방침

시행일: 2026년 11월 7일 · 개정일: 2026년 11월 8일 (Instagram·TikTok 추가)

chilla-collector(이하 "이 도구")는 채널 「우왕좌왕 최칠라」의 운영자(이하 "운영자")가 자기 계정의 통계를 자기 스프레드시트에 기록하기 위해 만든 비공개 도구입니다. 이 방침은 이 도구가 각 플랫폼의 공식 API로 어떤 정보를 읽고, 어디에 저장하며, 어떻게 삭제하는지를 설명합니다.

1. 수집하는 정보

운영자 본인이 승인한 계정에 대해서만, 각 플랫폼의 공식 API로 다음 정보를 읽습니다.

YouTube

  • 채널 정보: 채널 ID, 채널 이름, 구독자 수, 총 조회수, 영상 수
  • 영상 정보: 영상 ID, 제목, 길이, 공개 상태, 예약·공개 시각, 조회수·좋아요 수·댓글 수
  • YouTube Analytics 집계 지표: 일별 조회수, 시청 시간, 평균 시청 지속 시간, 유입 경로, 구간별 시청 지속률 등

Instagram

  • 계정 정보: 사용자 ID, 사용자 이름, 계정 유형, 팔로워 수, 팔로잉 수, 게시물 수
  • 게시물 정보: 미디어 ID, 유형, 캡션 앞부분, 링크, 게시 시각, 좋아요 수, 댓글 수
  • 인사이트 집계 지표: 게시물·릴스별 조회수, 도달, 저장, 공유, 상호작용 수, 릴스 평균·총 시청 시간, 계정의 일별 도달·조회·프로필 방문 수

TikTok

  • 계정 정보: open_id, 표시 이름, 사용자 이름, 팔로워 수, 팔로잉 수, 좋아요 수, 영상 수
  • 영상 정보: 영상 ID, 제목, 설명 앞부분, 링크, 길이, 게시 시각, 조회수·좋아요 수·댓글 수·공유 수

어느 플랫폼에서도 시청자·팔로워 개인을 식별하는 정보(개별 팔로워 목록, 댓글 작성자 정보, 메시지 등)는 읽지 않습니다. 인사이트·분석 값은 모두 플랫폼이 제공하는 집계 수치입니다.

2. 이용 목적

운영자 본인이 자기 게시물의 성과를 기록하고 다음 콘텐츠 제작에 참고하기 위해서만 사용합니다. 광고, 마케팅, 프로파일링, 다른 서비스 제공에 사용하지 않습니다.

3. 저장 위치와 보관

  • 수집한 정보는 운영자 본인의 Google 스프레드시트에만 저장됩니다. 별도 서버나 데이터베이스는 없습니다.
  • 승인 토큰(YouTube 갱신 토큰, Instagram 액세스 토큰, TikTok 액세스·갱신 토큰)은 해당 스프레드시트에 연결된 Google Apps Script의 스크립트 속성에만 저장되며, 스프레드시트 본문, 소스 코드 저장소, 외부 서버에 기록하지 않습니다.
  • TikTok 액세스 토큰은 Apps Script 캐시에 최대 24시간만 보관됩니다.
  • 수집한 통계는 운영자가 연결을 해제하거나 삭제하기 전까지 보관합니다.

4. 제3자 제공

수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 운영자 외에는 스프레드시트에 접근할 수 없습니다.

5. 접근 철회와 데이터 삭제

운영자는 언제든 아래 방법으로 접근 권한을 철회하고 데이터를 삭제할 수 있습니다.

플랫폼접근 권한 철회저장된 데이터·토큰 삭제
YouTubeGoogle 계정의 서드 파티 연결 화면에서 chilla-collector 제거도구의 「연결 해제·수집 데이터 삭제」 실행
InstagramInstagram 앱 설정 → 앱 및 웹사이트에서 제거도구의 Instagram 연결 해제 기능 실행
TikTokTikTok 앱 설정 → 보안 및 권한 → 앱 권한 관리에서 제거도구의 TikTok 연결 해제 기능 실행(토큰 철회 요청 포함)

연결 해제 기능은 해당 플랫폼의 정기 수집을 멈추고, 저장된 토큰과 API에서 받은 통계를 삭제합니다. 운영자가 직접 적어 둔 메모(에피소드 번호, 제작 메모 등)는 운영자 본인의 기록이므로 남습니다.

6. 플랫폼별 정책 준수

  • Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 서비스 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
  • Instagram API 이용은 Meta 플랫폼 약관과 개발자 정책을 따릅니다.
  • TikTok API 이용은 TikTok 개발자 서비스 약관을 따릅니다. 이 도구는 TikTok 콘텐츠를 저장하거나 재배포하지 않고 통계 수치만 기록합니다.
